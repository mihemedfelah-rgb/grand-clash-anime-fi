# Grand Clash — Anime Fight (iPhone-ready web prototype)

A self-contained 2D anime-inspired fighting game prototype made with HTML, CSS, and JavaScript. No external images, libraries, API keys, or tokens are required.

## Run it
- Open `index.html` in a browser or upload the folder to a static web host.
- For iPhone, rotate to landscape mode.
- Touch controls are on-screen. Keyboard controls also work:
  - A / Left Arrow: move left
  - D / Right Arrow: move right
  - Space / W / Up Arrow: jump
  - J: attack
  - K: Gatling
  - L: Haki special
  - Shift: dodge

## Files
- `index.html` — game layout and HUD
- `style.css` — responsive visual design and touch controls
- `game.js` — canvas rendering, movement, combat, enemy AI, effects, win/lose state

## Notes
This is an original fan-style prototype with simple canvas-drawn fighters, not official One Piece artwork. It is a playable starting point, not yet a Discord Activity. To share it online, publish the files to a static hosting service such as GitHub Pages; then a Discord Activity integration can be added as a separate step.
